# Client P1: foundation, landing, enquiry, OTP login, dashboard, plans

Date: 2026-10-12
Package: `frontend/client` (`@nextera/client`), branch `feat/client-foundation`

## Goal

Stand up the Nextera customer app at `nextera.srahira.com`: a public landing page with live plans and a
returns calculator, a public enquiry form, mobile OTP sign-in, and the first authenticated portal pages
(dashboard, plans list, plan detail). The look follows the Srahira brand, presented as "Nextera — a
Srahira platform".

## Server-only backend layer (`src/lib/backend/`)

- `client.ts`: `createBackendClient({baseUrl, serviceKey, fetch, timeoutMs})`.
  - Sends `x-service-key`, the bearer token, `x-forwarded-for` and `x-client-user-agent`.
  - Uses `cache: "no-store"` by default. An opt-in `revalidateSeconds` exists only for anonymous
    public reads.
  - Has a timeout and `redirect: "error"`.
  - Returns a typed `BackendResult<T>` and parses the `{error:{code,message,fields?,retryAfterSeconds?}}`
    envelope. Network failures and timeouts become `unavailable`.
- `server.ts` reads `NEXTERA_BACKEND_URL`, `NEXTERA_PORTAL_SERVICE_KEY` and
  `NEXTERA_BACKEND_TIMEOUT_MS` (zod-validated). It forwards the visitor IP and UA from `headers()`.
  `publicBackend()` skips the per-visitor headers so cached reads share one cache key.

## Session

- Cookie name: `__Host-nextera_portal_session` in production, `nextera_portal_session` otherwise. It is
  httpOnly, Secure, SameSite=Lax, Path=/, has no Domain, and expires when the backend session does.
- `proxy.ts` matches `/portal/:path*`:
  - With no cookie, it redirects to `/portal/login?next=<path>`.
  - When `/portal/login?expired=…` is requested, it clears the cookie.
- The `(app)` portal layout calls `/v1/auth/me` through a React-`cache`d `getCustomerSession()`.
  - On 401 it redirects to `/portal/login?expired=1`, which clears the cookie in the proxy.
  - A blocked account redirects with `expired=blocked`.
  - If the backend is down, the error boundary renders.
- `safePortalPath()` only allows `/portal` paths for `?next=`, never `/portal/login`, external URLs,
  protocol-relative URLs or backslashes.

## Pages

- `/`: hero, how it works, live plans (`GET /v1/plans`, `revalidate = 300`), the calculator,
  the risk and regulatory disclaimer, and CTAs.
  - If the backend is unreachable, a notice is shown and the calculator runs on an illustrative plan
    that is labelled as illustrative.
- `/enquire`: name, phone (Indian mobile), email?, interest, message?, and the honeypot `referral_note`.
  - Validated with zod server-side and rate-limited in memory per IP (5 per 10 minutes).
  - Posts to `POST /v1/leads`, which returns `201 {ref}`. Field errors from the backend map back
    onto the form. A 404, 5xx or network failure shows the "unavailable" fallback.
- `/portal/login`: phone, then `/v1/auth/otp/request`, then the code, then `/v1/auth/otp/verify`, then
  the cookie is set and the user is redirected to the safe `next`.
  - Shows `retryAfterSeconds` and a 30 s resend countdown.
  - Offers "use a different number" and maps the otp_invalid, otp_expired, otp_exhausted,
    account_blocked and rate_limited errors.
- Logout: a server action calls `/v1/auth/logout` best-effort, clears the cookie and redirects to login.
- `(app)` shell: header with Dashboard and Plans only (the pages that exist), the customer's name and
  phone, and a logout button. Responsive.
- `/portal`: welcome, KYC status from `/me`, CTA to plans.
- `/portal/plans`: plan cards and the interactive calculator.
- `/portal/plans/[slug]`: plan detail, calculator prefilled (`?amount=` optional), and a disabled
  Invest panel explaining that investing opens after KYC.

## Calculator

`src/lib/calculator.ts` is pure and does the following:

- Parses the rupee input (commas allowed, up to 2 decimals) into paise.
- Checks the amount against the plan's min and max.
- Calls `calculateReturns` and `projectSchedule` from contracts, starting today in IST.
- Produces chart points.

The client component renders the summary, a month-by-month table and a single-series SVG growth chart
with a hover crosshair. Test case: ₹13,50,000 at 8% gives ₹9,000 a month.
